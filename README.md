# 사진 용량 분할기 (PhotoSplitter)

한 폴더에 있는 사진들을 **폴더당 2GB 이하**(용량 변경 가능)로 나눠 담는 Windows 프로그램입니다.

## 사용법

1. `PhotoSplitter.exe` 실행
2. **사진 폴더** 선택 (저장 위치는 비워두면 사진 폴더 안에 만들어짐)
3. **미리보기**로 몇 개 폴더로 나뉘는지 확인
4. **나누기 실행**

결과 예시 (`여행사진` 폴더, 5.3GB):

```
여행사진_01  (1.98 GB)
여행사진_02  (1.99 GB)
여행사진_03  (1.33 GB)
```

### 옵션
- **폴더당 최대 용량**: 기본 2 GB (GB/MB 단위)
- **방식**: 복사(원본 유지, 기본값) / 이동
- **정렬**: 파일 이름순 / 수정 날짜순. 정렬 순서대로 채워 넣으므로 사진 순서가 유지됩니다.
- **모든 파일 포함**: 체크하면 동영상 등 사진이 아닌 파일도 함께 나눕니다.

참고
- 선택한 폴더 바로 안의 파일만 처리하고, 하위 폴더는 건드리지 않습니다.
- 파일 하나가 제한보다 크면 그 파일만 따로 한 폴더에 들어갑니다.
- 같은 이름의 파일이 이미 있으면 `이름 (1).jpg` 형태로 저장합니다.

## exe 받기 / 만들기

- **GitHub에서 받기**: 저장소의 **Actions** 탭 → 최신 "Build Windows exe" 실행 → 아래 **Artifacts**의 `PhotoSplitter-exe` 다운로드
- **직접 만들기**: Windows에 Python 3 설치 후 `build.bat` 더블클릭 → `dist\PhotoSplitter.exe`

## 개발

```
python src/app.py                               # 실행
python -m unittest discover -s tests            # 테스트
```
